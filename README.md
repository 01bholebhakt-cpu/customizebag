# Customize Bags

Personalised bags store. Your style. Your personal touch.

Static multi-page store (HTML, CSS, vanilla JS). Open `index.html`.
Orders are sent to WhatsApp. Edit contact, shipping, coupons and reviews in `core.js` (`CB.CFG`); products and prices are in `art.js`. Photos are in `assets/` and can be replaced with real ones (same file names).
